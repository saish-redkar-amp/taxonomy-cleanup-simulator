Reference · Know the difference

Delete vs. Block vs. Hide vs. Drop vs. Merge

ActionStops ingestion?Counts to limit?Reversible?What it's for
Delete Yes (future) No — frees limit Recover anytime Retire an event from the plan. History stays; it leaves dropdowns and future ingestion is blocked.
Block Yes (future) Still counts Unblock — but data during block is lost Quickly stop ingesting bad/redundant data before a code fix. Blocked data can't be recovered.
Hide No — keeps ingesting Still counts Fully, no data loss Declutter dropdowns for an event you might need later. Nothing is lost.
Drop filter No (query-time) Doesn't affect volume Fully, edit/delete filter Hide events from charts at query time. Doesn't apply to exports; data still ingested.
Merge / Transform No (query-time) Raw data untouched Unmerge anytime Consolidate duplicate events/properties into one, retroactively across all history.

Behavior sourced from Amplitude Docs. To permanently erase raw historical data (not just remove from the plan), use self-service data deletion or the User Privacy API — modeled here as "history retained".
